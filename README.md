# gdrive-receipts-to-mf-csv

Gmailに転送された領収書メール（または添付ファイル）をGoogleドライブへ自動保存し、Googleスプレッドシート上の台帳をベースにリネームとマネーフォワード(MF)用仕訳CSVの出力を行うシステムです。

---

## 1. 動作概要
1. **取込**: Gmailから自動転送されてきた領収書メール（`自動保存_処理待ち` ラベル）を、定期実行されるGASが検知します。
2. **一時保存**: 領収書ファイル（画像、PDF、または本文PDF）をGoogleドライブの指定フォルダに一時ファイル名（`[未処理]_...`）で保存し、同時に管理用スプレッドシート（台帳）へ新しい行を追加します。
3. **確認・入力**: ユーザーはスプレッドシート上で「取引日」「勘定科目」「取引先名」「取引金額」「メモ」を入力し、ステータスを「確定」に変更します。
4. **出力・リネーム**: スプレッドシートのメニューから「確定データのリネーム＆CSV出力」を実行すると、Googleドライブ上の実ファイルが確定情報に合わせた名称（`YYYY.MM.DD_勘定科目_取引先名_金額円_メモ.拡張子`）にリネームされ、同時にマネーフォワード用の仕訳CSV（Shift_JIS形式）が出力されます。

---

## 2. スプレッドシートの準備
1. Googleスプレッドシートを新規作成します。
2. シートの1行目（ヘッダー）に、左から以下の項目を入力してください。
   * **A列**: `ステータス` (ユーザーが「未処理」から「確定」に変更する箇所)
   * **B列**: `受信日時`
   * **C列**: `取引日付`
   * **D列**: `勘定科目`
   * **E列**: `取引先名`
   * **F列**: `取引金額`
   * **G列**: `メモ`
   * **H列**: `ファイル名`
   * **I列**: `ファイルID`
   * **J列**: `領収書リンク`

*※ データの入力規則を使って、A列にプルダウン（未処理, 確定, 完了）を設定したり、D列に勘定科目のプルダウンを設定しておくと便利です。*

---

## 3. GAS (Google Apps Script) の設定
1. 作成したスプレッドシートのメニュー「拡張機能」 ＞ 「Apps Script」を開きます。
2. 元からあるコードを削除し、同じディレクトリ内にある `code.js` のコードをすべて貼り付けます。
3. コードの最上部にある以下の設定箇所を書き換えます。
   * `FOLDER_ID` : 領収書を保存するGoogleドライブフォルダのID（URLの末尾英数字）を入力。
4. 画面上部の保存ボタン（フロッピーディスクのアイコン）を押します。

---

## 4. 自動トリガーの設定 (Gmailからの定期収集)
1. GASエディタの左メニューから「トリガー（時計マーク）」をクリックします。
2. 画面右下の「トリガーを追加」をクリックし、以下のように設定します。
   * 実行する関数: `importGmailReceipts`
   * イベントのソース: `時間主導型`
   * トリガーのタイプ: `時間ベースのタイマー`
   * 時間の間隔: `1時間おき`（または1日に1回など任意）
3. 保存をクリックし、Googleアカウントへのアクセス権限を許可します。

---

## 5. 使い方（運用フロー）
1. Gmailのフィルタ等を利用して、領収書メールに `自動保存_処理待ち` ラベルが付与されるようにします。
2. GAS（または手動実行）が動作すると、スプレッドシートに領収書が「未処理」として追加され、J列のリンクから中身を確認できるようになります。
3. 領収書を確認しながら、C〜G列に必要な情報（日付、勘定科目、取引先、金額など）を入力します。
4. 入力が完了した行のステータス（A列）を `確定` にします。
5. スプレッドシートのメニューに表示されている **「領収書管理」 ＞ 「確定データのリネーム＆CSV出力」** をクリックします。
6. Googleドライブ上の対象ファイルがリネームされ、マネーフォワード用のCSVファイルが自動的にドライブに出力されます。ステータスは `完了` に更新されます。
7. 生成されたCSVファイルをマネーフォワードの「仕訳帳入力」＞「インポート」から取り込みます。
