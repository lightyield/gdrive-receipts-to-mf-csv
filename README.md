# gdrive-receipts-to-mf-csv

Gmailに転送された領収書メール（または添付ファイル）をGoogleドライブへ自動保存し、Googleスプレッドシート上の台帳をベースにリネームとマネーフォワード(MF)用仕訳CSVの出力を行うシステムです。

---

## 1. 動作概要
1. **取込**: Gmailから自動転送されてきた領収書メール（`自動保存_処理待ち` ラベル）を、定期実行されるGASが検知します。
2. **一時保存**: 領収書ファイル（画像、PDF、または本文PDF）をGoogleドライブの指定フォルダに一時ファイル名（`[未処理]_...`）で保存し、同時に管理用スプレッドシート（台帳）へ新しい行を追加します。
3. **確認・入力**: ユーザーはスプレッドシート上で「取引日」「勘定科目」「取引先名」「取引金額」「メモ」を入力し、ステータスを「確定」に変更します。
4. **出力・リネーム**: スプレッドシートのメニューから「確定データのリネーム＆CSV出力」を実行すると、Googleドライブ上の実ファイルが確定情報に合わせた名称（`YYYY.MM.DD_勘定科目_取引先名_金額円_メモ.拡張子`）にリネームされ、同時にマネーフォワード用の仕訳CSV（Shift_JIS形式）が出力されます。

---

## 2. スプレッドシートの準備
1. Googleスプレッドシートを新規作成します。
2. シートの1行目（ヘッダー）に、左から以下の項目を入力してください。
   * **A列**: `受信日時`
   * **B列**: `取引日付`
   * **C列**: `勘定科目`
   * **D列**: `取引先名`
   * **E列**: `取引金額`
   * **F列**: `メモ`
   * **G列**: `ファイル名`
   * **H列**: `ファイルID`
   * **I列**: `領収書リンク`

*※ C列の勘定科目プルダウンは、GASのメニューから自動設定できます（詳細は「3. GAS (Google Apps Script) の設定」を参照してください）。*

---

## 3. GAS (Google Apps Script) の設定
1. 作成したスプレッドシートのメニュー「拡張機能」 ＞ 「Apps Script」を開きます。
2. 元からあるコードを削除し、同じディレクトリ内にある `code.js` のコードをすべて貼り付けます。
3. **「Drive API」サービスの追加**:
   - 画面左メニューの「サービス ＋」をクリックします。
   - リストから「Drive API」を選択し、「追加」をクリックします。
4. **「スクリプトのプロパティ」の設定**:
   - 画面左メニューの「プロジェクトの設定（歯車アイコン）」をクリックします。
   - 画面最下部にある「スクリプトのプロパティ」にて、「スクリプトのプロパティを追加」をクリックし、以下を設定します。
     - **プロパティ**: `FOLDER_ID`
     - **値**: 領収書を保存するGoogleドライブフォルダのID（フォルダを開いた際のURL末尾の英数字。例: `https://drive.google.com/drive/folders/1abc123...` の `1abc123...` 部分）
   - 「スクリプトのプロパティを保存」をクリックします。
5. エディタ画面に戻り、保存ボタン（フロッピーディスクのアイコン）を押します。
6. **勘定科目プルダウンの初期設定**:
   - スプレッドシートのタブをリロード（再読み込み）します。
   - メニューに追加された **「領収書管理」 ＞ 「勘定科目プルダウンを設定」** をクリックします。
   - 初回実行時は承認を求められるため、画面の指示に従ってアクセス権限を許可してください。
   - これにより、C列に以下の勘定科目プルダウンが自動設定されます（リスト外の手入力も可能です）。
     > 接待交際費、備品・消耗品費、旅費交通費、通信費、新聞図書費、車両費、荷造運賃、支払手数料、租税公課

---

## 4. 自動トリガーの設定 (Gmailからの定期収集)
1. GASエディタの左メニューから「トリガー（時計マーク）」をクリックします。
2. 画面右下の「トリガーを追加」をクリックし、以下のように設定します。
   * 実行する関数: `importGmailReceipts`
   * イベントのソース: `時間主導型`
   * トリガーのタイプ: `時間ベースのタイマー`
   * 時間の間隔: `1時間おき`（または1日に1回など任意）
3. 保存をクリックし、Googleアカウントへのアクセス権限を許可します。

---

## 5. 使い方（運用フロー）
1. Gmailのフィルタ等を利用して、領収書メールに `自動保存_処理待ち` ラベルが付与されるようにします。
2. GAS（または手動実行）が動作すると、スプレッドシートに領収書が自動追加され、I列のリンクから中身を確認できるようになります。
3. 領収書を確認しながら、B〜F列に必要な情報（日付、勘定科目、取引先、金額など）を入力します。
   - **勘定科目（C列）** はプルダウンから選択するか、リストにない場合は直接手入力することもできます。
4. スプレッドシートのメニューに表示されている **「領収書管理」 ＞ 「未処理データのリネーム＆CSV出力」** をクリックします。
5. 金額や勘定科目に空欄があるとエラーが表示されます。すべて入力されていれば、Googleドライブ上の対象ファイルがリネームされ、マネーフォワード用のCSVファイルが自動的にドライブに出力されます。処理した行のファイル名（G列）は、数式から **実際のファイル名（文字列）** に更新されます。
6. 生成されたCSVファイルをマネーフォワードの「仕訳帳入力」＞「インポート」から取り込みます。
