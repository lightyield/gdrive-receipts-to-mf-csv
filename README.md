# gdrive-receipts-to-mf-csv

Gmailに転送された領収書メールの自動収集のほか、スマートフォン等で撮影した領収書写真の手動アップロードにも対応し、Googleスプレッドシート上の台帳をベースにリネームとマネーフォワード(MF)用仕訳CSVの出力を行うシステムです。

---

## 1. 動作概要

### A. Gmailからの自動収集
1. **取込**: Gmailから自動転送されてきた領収書メール（`自動保存_処理待ち` ラベル）を、定期実行されるGASが検知します。
2. **一時保存**: 領収書ファイル（画像、PDF、または本文PDF）をGoogleドライブの `領収書/Gmail/処理待ち` フォルダに一時ファイル名（`[未処理]_...`）で保存し、同時に管理用スプレッドシート（台帳）へ新しい行を追加します。

### B. 自分で撮影した写真等の手動取込
1. **アップロード**: Googleドライブの `領収書/手動/処理待ち` フォルダへ、ファイル名を `YYYYMMDD_勘定科目_取引先名_金額円_メモ.拡張子` に設定して手動アップロードします（例: `20260811_旅費交通費_タクシー_1500円_東京出張.jpg`、メモは省略可能）。
   *(※ `YYYY.MM.DD` のようなドット区切りや、金額の `2,731円` のようなカンマ表記にも対応しています)*
2. **取込**: スプレッドシートのメニューから「手動アップロード領収書を取込」を実行します。
3. **移動と台帳登録**: ファイル名から取引情報を自動的にパースしてスプレッドシートへ行を追加し、ファイルは `領収書/手動/処理済み` フォルダに自動的に移動されます。
   *(※ 適合しないファイル名のものは処理されず「処理待ち」フォルダに残されます)*

### 共通の確定・出力処理
1. **確認・入力**: ユーザーはスプレッドシート上で取引情報を確認・調整します（Gmailから取り込まれた未処理のものは、ここで日付や金額, 勘定科目等を入力します）。
2. **リネームと移動**: スプレッドシートのメニューから「Gmail未処理データのリネーム」を実行すると、A列「取込経路」の値が「Gmail」かつH列「ファイル名」が未確定（数式）の対象レコードについて、Googleドライブ上の対象ファイルが `領収書/Gmail/処理済み` フォルダへ移動され、同時に確定情報に合わせた名称（`YYYY.MM.DD_勘定科目_取引先名_金額円_メモ.拡張子`）にリネームされます。
3. **CSV出力**: スプレッドシートのメニューから「MFクラウド会計向けCSV出力」を実行すると、確定した（リネーム済みの）レコードを対象に、マネーフォワード用の仕訳CSV（Shift_JIS形式）が出力されます。
4. **レコード削除**: スプレッドシートのメニューから「CSV出力済みレコードを削除」を実行すると、CSV出力が完了したレコードを一括して削除します（Googleドライブ上の実ファイルは削除されず残ります）。

## 2. スプレッドシートの準備
1. Googleスプレッドシートを新規作成します。
2. シートの **1行目（集計行）** には、プログラムから自動で件数と合計金額の集計用数式がセットされます。手動での入力は不要です。
   * **A1**: `=COUNTA(A3:A)` （合計件数の数式）
   * **F1**: `=SUM(F3:F)` （合計金額の数式）
3. シートの **2行目（ヘッダー）** に、左から以下の項目を入力してください。
   * **A列**: `取込経路`
   * **B列**: `受信日時`
   * **C列**: `取引日付`
   * **D列**: `勘定科目`
   * **E列**: `取引先名`
   * **F列**: `取引金額`
   * **G列**: `メモ`
   * **H列**: `ファイル名`
   * **I列**: `ファイルID`
   * **J列**: `領収書リンク`
   * **K列**: `CSV出力`

*※ D列の勘定科目プルダウンは、GASのメニューから自動設定できます（詳細は「3. GAS (Google Apps Script) の設定」を参照してください）。*

### 既存スプレッドシートからの移行手順
すでに本システムを使用している既存のスプレッドシートがある場合は、以下の手順で移行を行ってください。
1. スプレッドシートの **1行目** を選択し、右クリックして **「上に1行挿入」** を行います。これにより、空の1行目が追加され、既存のヘッダーが2行目に、データ行が3行目以降にずれます。
2. GASコード（`code.js`）を最新にアップデートしてデプロイします。
3. スプレッドシートのメニューから **「領収書管理」 ＞ 「勘定科目プルダウンを設定」** を実行します。
   * これにより、1行目に集計数式、2行目にヘッダーが自動で設定・更新され、入力規則、フォーマット、およびファイル名の数式がすべて新しい構成に対応するように修復されます。

## 3. GAS (Google Apps Script) の設定
1. 作成したスプレッドシートのメニュー「拡張機能」 ＞ 「Apps Script」を開きます。
2. 元からあるコードを削除し、同じディレクトリ内にある `code.js` のコードをすべて貼り付けます。
3. **「Drive API」サービスの追加**:
   - 画面左メニューの「サービス ＋」をクリックします。
   - リストから「Drive API」を選択し、「追加」をクリックします。
4. **「スクリプトのプロパティ」の設定**:
   - 画面左メニューの「プロジェクトの設定（歯車アイコン）」をクリックします。
   - 画面最下部にある「スクリプトのプロパティ」にて、「スクリプトのプロパティを追加」をクリックし、以下を設定します。
     - **プロパティ**: `FOLDER_ID`
     - **値**: 領収書を保存するGoogleドライブフォルダのID（フォルダを開いた際のURL末尾の英数字）
     - **プロパティ**: `GMAIL_QUEUE_FOLDER_ID`（任意）
     - **値**: Gmail取込用の「処理待ち」フォルダID（未設定の場合は、`FOLDER_ID` フォルダ直下の `Gmail/処理待ち` を自動探索します）
     - **プロパティ**: `GMAIL_DONE_FOLDER_ID`（任意）
     - **値**: Gmail確定後の「処理済み」フォルダID（未設定の場合は、`FOLDER_ID` フォルダ直下の `Gmail/処理済み` を自動探索します）
     - **プロパティ**: `MANUAL_QUEUE_FOLDER_ID`（任意）
     - **値**: 手動取込用の「処理待ち」フォルダID（未設定の場合は、`FOLDER_ID` フォルダ直下の `手動/処理待ち` を自動探索します）
     - **プロパティ**: `MANUAL_DONE_FOLDER_ID`（任意）
     - **値**: 手動取込用の「処理済み」フォルダID（未設定の場合は、`FOLDER_ID` フォルダ直下の `手動/処理済み` を自動探索します）
   - 「スクリプトのプロパティを保存」をクリックします。
5. エディタ画面に戻り、保存ボタン（フロッピーディスクのアイコン）を押します。
6. **勘定科目プルダウンの初期設定**:
   - スプレッドシートのタブをリロード（再読み込み）します。
   - メニューに追加された **「領収書管理」 ＞ 「勘定科目プルダウンを設定」** をクリックします。
   - 初回実行時は承認を求められるため、画面の指示に従ってアクセス権限を許可してください。
   - これにより、C列に以下の勘定科目プルダウンが自動設定されます（リスト外の手入力も可能です）。
     > 接待交際費、備品・消耗品費、旅費交通費、通信費、新聞図書費、車両費、荷造運賃、支払手数料、租税公課

---

## 4. 自動トリガーの設定 (Gmailからの定期収集)
1. GASエディタの左メニューから「トリガー（時計マーク）」をクリックします。
2. 画面右下の「トリガーを追加」をクリックし、以下のように設定します。
   * 実行する関数: `importGmailReceipts`
   * イベントのソース: `時間主導型`
   * トリガーのタイプ: `時間ベースのタイマー`
   * 時間の間隔: `1時間おき`（または1日に1回など任意）
3. 保存をクリックし、Googleアカウントへのアクセス権限を許可します。

## 5. 使い方（運用フロー）

### A. Gmailからの自動収集の場合
1. Gmailのフィルタ等を利用して、領収書メールに `自動保存_処理待ち` ラベルが付与されるようにします。
2. GAS（または手動実行）が動作すると、スプレッドシートに領収書が自動追加され、同時に添付ファイル等は `領収書/Gmail/処理待ち` フォルダに保存されます。I列のリンクから中身を確認できるようになります。
3. 領収書を確認しながら、B〜F列に必要な情報（日付, 勘定科目, 取引先, 金額など）を入力します。

### B. 写真やPDFを手動で取り込む場合
1. Googleドライブの `領収書/手動/処理待ち` フォルダに、以下の命名規則でファイルをアップロードします。
   - 規則: `YYYYMMDD_勘定科目_取引先名_金額円_メモ.拡張子` (例: `20260811_旅費交通費_タクシー_1500円_東京出張.jpg`、メモは省略可能)
2. スプレッドシートのメニューから **「領収書管理」 ＞ 「手動アップロード領収書を取込」** をクリックします。
3. 適合するファイル名のデータがスプレッドシートへ自動パースされて行追加され、実ファイルは `領収書/手動/処理済み` フォルダに移動されます。
   - ※ 適合しないファイル名のファイルは「処理待ち」フォルダに残されるため、後から名前を修正して再実行できます。

### C. 確定データのリネーム ＆ CSV出力 (共通)
1. スプレッドシートの入力内容を確認・修正します。
2. メニューから **「領収書管理」 ＞ 「Gmail未処理データのリネーム」** をクリックします。
   * 金額や勘定科目に空欄があるとエラーが表示されます。すべて入力されていれば、A列の取込経路が「Gmail」かつH列のファイル名が未確定（数式）の対象レコードについて、Googleドライブ上の対象ファイルが `領収書/Gmail/処理済み` フォルダに移動された上でリネームされます。処理した行のファイル名（H列）は、数式から **実際のファイル名（文字列）** に更新されます。
3. メニューから **「領収書管理」 ＞ 「MFクラウド会計向けCSV出力」** をクリックします。
   * 確定（リネーム済み）したデータからマネーフォワード用のCSVファイルが自動的にドライブに出力されます。
4. 生成されたCSVファイルをマネーフォワードの「仕訳帳入力」＞「インポート」から取り込みます。
5. マネーフォワードへの取り込み完了後、メニューから **「領収書管理」 ＞ 「CSV出力済みレコードを削除」** をクリックします。
   * 確認ダイアログで「はい」を選択すると、CSV出力が完了したレコード（K列にCSVファイル名が書き込まれている行）がスプレッドシート上から一括で削除されます。
   * ※ 証憑保存義務を考慮し、Googleドライブ上の実ファイルは削除されずに残ります。

## 6. ローカル開発環境と自動デプロイの設定 (clasp)

ローカル（Git）のコードをコマンドラインから直接GASプロジェクトへデプロイできるようにするため、Google公式のCLIツール **clasp** を導入しています。

### セットアップ手順

1. **Google Apps Script APIを有効にする**:
   - [Google Apps Script ユーザー設定](https://script.google.com/home/usersettings) にアクセスし、**「Google Apps Script API」** を **「オン」** に変更します。

2. **依存パッケージのインストール**:
   - リポジトリのルートディレクトリで以下を実行します。
     ```bash
     npm install
     ```

3. **Googleアカウントへのログイン**:
   - 以下のコマンドを実行するとブラウザが起動します。GASプロジェクトを編集可能なアカウントでログインし、アクセスを許可してください。
     ```bash
     npm run login
     ```

4. **設定ファイルの配置とGASからのコード取得**:
   - ローカルの `.clasp.json` にGASプロジェクトのスクリプトIDを設定します。
     ```json
     {
       "scriptId": "YOUR_SCRIPT_ID_HERE",
       "rootDir": "./"
     }
     ```
     *(※ `.clasp.json` およびログイン情報が含まれる `.clasprc.json` は、セキュリティー保護のため `.gitignore` によってGit管理から自動的に除外されます)*
   - 準備ができたら、一度以下のコマンドで既存のGASプロジェクトから設定（`appsscript.json`）をダウンロードします。
     ```bash
     npm run pull
     ```

### デプロイ方法

ローカルのコード（`code.js` など）を変更後、以下のコマンドを実行するだけで自動的にGASへ反映されます。
```bash
npm run deploy
```
