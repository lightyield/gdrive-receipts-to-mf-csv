# gdrive-receipts-to-mf-csv

Gmailに転送された領収書メールの自動収集のほか、スマートフォン等で撮影した領収書写真の手動アップロードにも対応し、Googleスプレッドシート上の台帳をベースにマネーフォワード(MF)用仕訳CSVの出力を行うシステムです。

---

## 1. 動作概要

すべての領収書は以下の統一されたフォルダ構成とシンプルなワークフローで管理されます。

### フォルダ構成

```text
領収書 (FOLDER_ID)
　├ 01.受付
　├ 02.リネーム済み
　└ 03.インポート済み
```

### 運用フロー

```mermaid
flowchart TD
    subgraph 1. 収集・受付
        A1[Gmail領収書メール] -->|GAS定期収集| B[01.受付]
        A2[写真/PDF手動アップ] -->|手動アップロード| B
    end

    subgraph 2. リネーム
        B -->|ローカル・OCRスキル等でリネーム| C[02.リネーム済み]
    end

    subgraph 3. 台帳登録
        C -->|GAS: リネーム済み領収書の取込| D[スプレッドシート台帳]
        C -.->|実ファイル自動移動| E[03.インポート済み]
    end

    subgraph 4. 会計連携
        D -->|GAS: MFクラウド会計向けCSV出力| F[マネーフォワード仕訳CSV]
        D -->|GAS: CSV出力済みレコードを削除| G[台帳クリーンアップ]
    end
```

1. **収集・受付**:
   - **Gmailからの自動収集**: 定期実行されるGASが `自動保存_処理待ち` ラベルの付いたメールを検知し、添付ファイルまたは本文PDFを `01.受付` フォルダに保存します（この時点ではスプレッドシートには記帳されません）。
   - **手動アップロード**: 写真やPDFを `01.受付` フォルダへアップロードします。
2. **リネーム**:
   - `01.受付` フォルダ内のファイルを、ローカル環境やOCRスクリプト等を用いて命名規則に沿った名称に変更し、`02.リネーム済み` フォルダへ移動します。
   - **ファイル命名規則**: `YYYY.MM.DD_勘定科目_取引先名_金額円_メモ.拡張子`
     - 例: `2026.08.18_旅費交通費_タクシー_1500円_東京出張.jpg`（メモは省略可能）
     - ※ `YYYYMMDD` などの連続数字や、金額の `1,500円` などのカンマ表記にも対応しています。
3. **台帳取込**:
   - スプレッドシートのメニューから **「リネーム済み領収書の取込」** を実行します。
   - `02.リネーム済み` フォルダ内のファイル名から取引情報（日付・勘定科目・取引先・金額・メモ）が自動的にパースされてスプレッドシート台帳に行追加され、実ファイルは `03.インポート済み` フォルダへ自動移動されます。
   - *(※ 命名規則に適合しないファイルはスキップされ、`02.リネーム済み` フォルダに残されます)*
4. **CSV出力**:
   - スプレッドシートのメニューから **「MFクラウド会計向けCSV出力」** を実行すると、未出力の確定レコードを対象にマネーフォワード用仕訳CSV（Shift_JIS形式）が出力されます。
5. **レコード削除**:
   - マネーフォワードへの取込完了後、メニューから **「CSV出力済みレコードを削除」** を実行すると、CSV出力済みのレコードを一括削除します（Googleドライブ上の実ファイルは残ります）。

## 2. スプレッドシートの準備

1. Googleスプレッドシートを新規作成します（データ入力用シート）。
2. シートの1行目（ヘッダー）に、左から以下の項目を設定します（メニューの「スプレッドシート初期設定」から自動設定可能）。
   * **A列**: `登録日時`
   * **B列**: `取引日付`
   * **C列**: `勘定科目`
   * **D列**: `取引先名`
   * **E列**: `取引金額`
   * **F列**: `メモ`
   * **G列**: `ファイル名`
   * **H列**: `ファイルID`
   * **I列**: `領収書リンク`
   * **J列**: `CSV出力`

### 自動集計シートについて
GASの初期設定（メニューの「スプレッドシート初期設定」）を実行すると、自動的に **「集計」** という名前の別シートが作成・更新されます。
この「集計」シートでは、データ入力用シートと連動して以下の集計値が自動計算されます。
* **勘定科目ごとの取引件数・合計金額**
* **全体の総合計（件数・金額）**

## 3. GAS (Google Apps Script) の設定

1. スプレッドシートのメニュー「拡張機能」 ＞ 「Apps Script」を開きます。
2. `code.js` のコードを貼り付けます（または clasp を用いてデプロイします）。
3. **「Drive API」サービスの追加**:
   - 画面左メニューの「サービス ＋」をクリックします。
   - リストから「Drive API」を選択し、「追加」をクリックします。
4. **「スクリプトのプロパティ」の設定**:
   - 画面左メニューの「プロジェクトの設定（歯車アイコン）」をクリックします。
   - 「スクリプトのプロパティ」にて以下を設定します。
     - **プロパティ**: `FOLDER_ID`（必須）
     - **値**: 親フォルダ「領収書」のGoogleドライブフォルダID
     - **プロパティ**: `INBOX_FOLDER_ID`（任意）
     - **値**: 「01.受付」フォルダID（未設定の場合は `FOLDER_ID` 直下の `01.受付` を自動探索・作成）
     - **プロパティ**: `RENAMED_FOLDER_ID`（任意）
     - **値**: 「02.リネーム済み」フォルダID（未設定の場合は `FOLDER_ID` 直下の `02.リネーム済み` を自動探索・作成）
     - **プロパティ**: `IMPORTED_FOLDER_ID`（任意）
     - **値**: 「03.インポート済み」フォルダID（未設定の場合は `FOLDER_ID` 直下の `03.インポート済み` を自動探索・作成）
5. **勘定科目プルダウンと初期設定**:
   - スプレッドシートをリロードし、メニューに追加された **「領収書管理」 ＞ 「スプレッドシート初期設定」** を実行します。
   - これにより、A1:J1 のヘッダー、C列の勘定科目プルダウン、E列の金額フォーマット、および「集計」シートが自動セットアップされます。

## 4. 自動トリガーの設定 (Gmailからの定期収集)

1. GASエディタの左メニューから「トリガー（時計マーク）」をクリックします。
2. 「トリガーを追加」をクリックし、以下のように設定します。
   * **実行する関数**: `importGmailReceipts`
   * **イベントのソース**: `時間主導型`
   * **トリガーのタイプ**: `時間ベースのタイマー`
   * **時間の間隔**: `1時間おき`（または1日に1回など任意）
3. 保存をクリックし、Googleアカウントへのアクセス権限を許可します。

## 5. 使い方（メニュー操作一覧）

スプレッドシートのメニュー「領収書管理」から以下の操作を行います。

| メニュー名 | 説明 |
| :--- | :--- |
| **Gmailから領収書を取得** | Gmailで `自動保存_処理待ち` ラベルが付いた領収書メールを検知し、添付ファイルまたは本文PDFを `01.受付` フォルダに保存します。 |
| **リネーム済み領収書の取込** | `02.リネーム済み` フォルダ内のファイル名から取引情報をパースして台帳に行追加し、実ファイルを `03.インポート済み` フォルダへ移動します。 |
| **MFクラウド会計向けCSV出力** | J列が空の確定レコードを対象に、マネーフォワード用の仕訳インポートCSV（Shift_JIS形式）を親フォルダに出力し、J列に出力ファイル名を記録します。 |
| **CSV出力済みレコードを削除** | CSV出力が完了したレコード（J列にファイル名が記録された行）をスプレッドシート台帳から一括削除します。実ファイルは削除されません。 |
| **スプレッドシート初期設定** | ヘッダー・勘定科目入力規則・金額表示フォーマット・集計シートを最新状態に設定・修復します。 |

---

## 6. ローカル開発環境と自動デプロイの設定 (clasp)

### セットアップ手順

1. **Google Apps Script APIを有効にする**:
   - [Google Apps Script ユーザー設定](https://script.google.com/home/usersettings) で「Google Apps Script API」を「オン」にします。

2. **依存パッケージのインストール**:
   ```bash
   npm install
   ```

3. **Googleアカウントへのログイン**:
   ```bash
   npm run login
   ```

4. **テストの実行**:
   ```bash
   npm test
   ```

5. **GASプロジェクトへのデプロイ**:
   ```bash
   npm run deploy
   ```
